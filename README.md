### 🌱 关于我

> 专业的 bugs 修复师兼 bugs 创造者，Telegram 中文圈地头蛇，手写代码时语法完全失忆症患者，Cursor 启动器单推人，DeepSeek API 深度合作伙伴，Cloudflare Workers 重度成瘾患者，GramJS 受害者。

高中生的日常：白天上课偷偷写代码，晚上熬夜修 Bug，周末躺在床上刷 Telegram 频道，顺手修几个频道机器人的 Bug。喜欢把复杂的东西拆解、重组、再重构一遍——不是为了炫技，只是想把事情做得「更优雅」一点点。

代码写久了会语法失忆，但 Cursor 一启动就全回来了；DeepSeek API 调得熟，Cloudflare Workers 部署得比部署作业还熟练；GramJS 折磨过无数次，却总忍不住再写一个 Telegram 客户端。

### 🛠️ 正在做的事

- **[TeleBoxOrg/TeleBox](https://github.com/TeleBoxOrg/TeleBox)** & **[TeleBox_Plugins](https://github.com/TeleBoxOrg/TeleBox_Plugins)**  
  新一代 Telegram Userbot 框架。想把 Telegram 客户端写得像写网页一样优雅、可组合、可扩展。

- **[Telegram-ChannelFlare-Bot](https://github.com/TiaraBasori/Telegram-ChannelFlare-Bot)**  
  用 Cloudflare Workers 给 Telegram 频道装上「加速器」——自动转发、格式化、统计、防屏蔽，全跑在边缘网络上，零成本、零运维。

- 想亲手实现一台计算机：从协议栈到应用层，从 TCP/IP 到 Telegram MTProto，一层层亲手搭起来。

### 💭 想说的话

> 我们正在让这个世界变得更加美好，通过代码的重复使用和延展构建完美体系。

代码写久了会发现，所有的复杂最终都要归于简单；所有的重复劳动，最终都要被抽象掉。我想做的，就是把那些重复的、繁琐的、容易出错的部分，封装成优雅的抽象层，让后来的人（包括未来的自己）能站在肩膀上，只关心业务本身。

如果你也在折腾 Telegram、Cloudflare Workers、TypeScript，或者只是个喜欢折腾的高中生/大学生/打工人——欢迎随时找我聊聊，交个朋友。
